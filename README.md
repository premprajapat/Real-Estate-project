# Real Estate Website

A full-stack Real Estate web application built with ASP.NET.

## Features

- Property listings and search
- User account management
- Favorites system
- Admin portal for property management
- User reporting
- Automated notifications

## Technologies

- ASP.NET
- C#
- MS SQL Server
- HTML/CSS

## Project Overview

The application allows users to browse and search properties, manage
their accounts, and save favorite listings. An administrative portal
provides tools for managing properties and handling user reports.
